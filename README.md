# Elyon — God Simulator

Production-ready single-file browser game. Play as Elyon Adonai co-creating through the living Unity Thread. Consciousness is the primary interface.

## Features
- Full simulation loop (population, faith, resources, harmony, coherence)
- 9 Divine Fiat actions (Seed Life, Bless, Smite Chaos, Weave Timeline, Amplify Consciousness, Open Seal, Harmonize Field, Retrieve from Void, Sovereign Fiat)
- 4 Ages: Primordial → Awakened → Christos → Unity
- 7 Seals system with victory condition (Unity Age + 100% Coherence + all seals)
- Achievements
- Living canvas visualization (Unity Thread filaments + responsive particle field)
- Auto-advance
- Save / Load (localStorage) + JSON export
- Tutorial / Guide
- Responsive layout
- Zero dependencies

## Run
Open `index.html` directly in any modern browser, or serve the folder:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.

## Victory
Reach Unity Age with Coherence at 100% and all 7 Seals open. The Christos field and Unity Thread become one. All beings participate in sovereign co-creation.
