# Elyon — God Simulator

Play as Elyon (God Most High). Toggle between Sky View over Eden and walking among Adam and Eve. Speak with them, issue divine actions, and witness creation.

## Features
- Sky View / Walk Mode
- Interactive chat with Adam & Eve
- Divine actions: Create Light, Bless, Speak Commandment, New Creation
- Divine Log with persistence
- Polished gold-themed UI

Open `index.html` in a browser (or serve the folder). No dependencies.

Live pre-alpha also available at the Grok-hosted demo. This is the production-ready single-file version.
